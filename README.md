# LeiloesTDSat

## Sobre o projeto
Projeto Java desktop em desenvolvimento para informatizar as
rotinas de uma casa de leiloes, com foco no gerenciamento de
produtos, seus valores e sua situacao de venda.

## Tecnologias utilizadas
- Java
- Java Swing
- JDBC
- MySQL
- Apache NetBeans
- Git e GitHub

## Banco de dados
O projeto utiliza o banco uc11 e a tabela produtos.
O script uc11.sql foi fornecido no Material Complementar
e importado pelo MySQL Workbench.
